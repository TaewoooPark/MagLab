# skills/ — Bundled SKILL.md skills

MagLab skills follow the **SKILL.md open standard** (agentskills.io) — portable and
compatible with Claude Code, Codex, Gemini CLI, and similar agents (§5.6·§5.17).

## Structure

A skill is a directory (name = `name`):

```
skills/<name>/
  SKILL.md          # required — frontmatter + body
  scripts/          # executable code (optional)
  references/       # domain docs · API references (optional)
  assets/           # templates (optional)
  evals/            # test cases (optional)
```

## SKILL.md frontmatter

- Portable fields: `name` (1–64 char kebab) · `description` (trigger, ≤1024 chars) ·
  `license` · `compatibility` · `metadata` (free key-value).
- MagLab extensions: `user-invocable` · `disable-model-invocation` (safety-critical) ·
  `paths` (auto-activation glob) · `allowed-tools` · `context: fork`.

## Three-level progressive disclosure

- **L1** — `name`+`description` only, always loaded at startup (~100 tokens/skill).
- **L2** — SKILL.md body, loaded on trigger (<5k tokens recommended, ≤500 lines).
- **L3** — bundled files (`scripts/`·`references/`), loaded only on explicit access/execution.

The `core/skills.py` loader discovers skills from `skills/`, `.maglab/skills/`, and
`~/.local/share/maglab/skills/`. The full catalog is in `plan/11-appendices.md`
Appendix C. Instrument skills are auto-generated by MagLab from manuals (§13.3).
