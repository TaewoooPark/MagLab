## Critical Gaps (Ranked by Severity)

### 1. OpenAlex Abstract Always Empty (Bug — Data Loss)
**File:** `maglab/literature/connectors.py:334`
**Severity:** High — every OpenAlex record has an empty abstract, breaking keyword extraction quality and RAG content for any OpenAlex-sourced paper.
**Fix:** Replace `(work.get("abstract_inverted_index") and "") or ""` with an inverted-index reconstruction function:
```python
def _reconstruct_abstract(inv: dict) -> str:
    if not inv:
        return ""
    pos_word = sorted(
        ((pos, word) for word, positions in inv.items() for pos in positions)
    )
    return " ".join(word for _, word in pos_word)
```
