MagLab Beamer slide template
============================

Template file: template.tex
Format:        LaTeX/Beamer
Loaded by:     SlidesDrafter (fmt="beamer")

Placeholder tokens replaced by SlidesDrafter at render time:
  %%TITLE%%   — presentation title
  %%AUTHOR%%  — presenter name (or [FILL: Author])
  %%SLIDES%%  — rendered \begin{frame}...\end{frame} blocks

Theme: Madrid + default colour theme.
MagLab blue accent colour: RGB(0, 83, 161).

If this file is absent, SlidesDrafter falls back to inline Beamer generation
(backward-compatible fallback defined in slide_drafter.py:SlideDeck.to_beamer_tex).
