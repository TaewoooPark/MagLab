> result reaches you.

---

## Why MagLab

Experimental spintronics groups face a fragmented toolchain: separate scripts for
micromagnetic simulation, effect fitting (ST-FMR, ISHE, anomalous Hall, …), literature
search, figure generation, and manuscript drafting — none of them talk to each other,
and none of them record where a number came from.

MagLab integrates the full research lifecycle in one tool built on a strict principle:
the **LLM reasons and plans; deterministic engines compute**. There are no benchmark
numbers invented by a language model, no citations hallucinated from a plausible-sounding
title, no figure data generated by sampling a neural network. Every DataPoint carries a
provenance type (`SIMULATED | MEASURED | THEORY | LITERATURE | FITTED`), a source
reference, and SI units — and an oracle hook blocks physically impossible inputs before
any computation runs.

## Features by research lifecycle phase

| Phase | What MagLab does |
|---|---|
| **Literature** | Multi-source search (OpenAlex · Semantic Scholar · arXiv · Crossref), author-network graph, evidence matrix, automated citation audit (DOI · retraction · OA), RAG-based literature review |
| **Materials** | Curated magnetic-material database (Ms, A, K, α, T_C, g-factor; DOI-sourced), Materials Project / OPTIMADE builder |
| **Physics** | Deterministic formula library (exchange length, Bloch wall width, FMR frequency, domain-wall velocity, skyrmion Hall angle, …); oracle range checker; SI unit conversion |
| **Simulation** | Micromagnetic single-scale (OOMMF / MuMax3 / magnum.np backends); DFT → atomistic (VAMPIRE) → micromagnetic multiscale pipeline; macrospin and two-sublattice LLG solvers |
| **Fitting** | Effect registry: AMR, AHE, OHE, PHE, SMR, USMR, GMR/TMR, Orbital Hall, Topological Hall, FMR/Kittel, Gilbert damping, ST-FMR (ξ_DL extraction), SOT harmonic Hall (PHE-corrected), spin pumping / ISHE, domain-wall, skyrmion / Thiele, Curie-temperature, hysteresis — all via lmfit, all with provenance-tagged FitResult |
| **Device FoM** | Figure-of-merit registry: MTJ, spin-valve sensor, SOT logic, magnon transport, and more |
| **Instruments** | VISA/SCPI workflow (scaffold, script, safety check including temperature limits); SCPI sequence validation; manual ingestion and RAG; PyVISA-sim mock mode |
| **Ralph loop** | Autonomous hypothesis → experiment → analysis → iterate engine with best-first tree search, budget tracking, checkpoint/resume, and optional per-iteration git commits |
| **Figures** | Data-plot renderer (Matplotlib + SciencePlots), schematic primitives catalog (Hall bar, MTJ pillar, Bloch/Néel domain wall, skyrmion, multilayer stack, …), micromagnetics visualiser (quiver + colorwheel), composition engine, provenance-tagged export |
| **Lab notebook** | Electronic lab notebook (ELN) — structured notes, search, measurement planning, design-of-experiments, active-learning planner |
| **Review** | Multi-persona reviewer panel (experimentalist · theorist · referee), meta-reviewer consensus/dissent, APL Matters rubric, disclosure of AI assistance |
| **Authoring** | Journal section drafter (RevTeX · IEEEtran · elsarticle · SN Journal · Advanced Materials · Word), BibTeX manager, citation auditor, data vault, slides (PowerPoint), poster |
| **Communications** | Cover letter, revision letter, response to reviewers (rebuttal), conference abstract, grant text, academic e-mail |
| **Gateway** | Slack · Telegram · Discord bot runner with proactive notifications; daemon management |
| **Hypotheses** | Structured hypothesis generation with evidence-basis and falsifiability metadata |

## Verifiable orchestrator — the core principle

```
┌─────────────────────────────────────────────────────────────┐
│                        MagLab agent                         │
│                                                             │
│  ┌──────────────┐   tool calls   ┌─────────────────────┐   │
│  │  LLM layer   │ ─────────────► │  Deterministic       │   │
│  │  (reasoning, │ ◄───────────── │  tools (physics ·    │   │
│  │   planning,  │  DataPoint +   │  sim · fit · lit ·   │   │
│  │   drafting)  │  provenance    │  figure · instr)     │   │
│  └──────────────┘                └─────────────────────┘   │
│          │                                │                 │
│          ▼                                ▼                 │
│  ┌────────────────────────────────────────────────────┐     │
│  │  Verification layer                                 │     │
│  │  1. Schema check  2. Physics oracle  3. Trust gate  │     │
│  │  4. Honesty gate (blocks bare floats in output)     │     │
│  └────────────────────────────────────────────────────┘     │
│          │                                                   │
│          ▼                                                   │
│  W3C PROV ledger  ─►  every result traceable to its source  │
└─────────────────────────────────────────────────────────────┘
```

**Three layers that must never blur:**

1. **LLM** — reasoning, planning, tool selection, narrative drafting, figure code authoring.
   Nothing beyond this.
2. **Deterministic tools** — simulation, fitting, theoretical formulae, units, materials,
   literature retrieval, citation verification, figure rendering.
   All numbers, citations, and figure data originate exclusively here.
3. **Provenance** — source and lineage of every `DataPoint`, citation, and decision (W3C PROV).

**Honesty gates** run at two points: the oracle hook fires before any physics tool call
(blocking unphysical parameters with a physics reason); `HonestyGate` fires at the REPL
output boundary (blocking bare float values not wrapped in a `DataPoint`).

## Installation

Python 3.11–3.13 required. All core modules install without a GPU or a live LLM key.

```sh
# Recommended — create an isolated env first
uv venv --python 3.12 && source .venv/bin/activate

# Core (physics · provenance · CLI · REPL · PROV ledger)
uv pip install -e .

# Install only what you need — extras are independent
uv pip install -e ".[llm]"         # LLM backends (litellm + Ollama)
uv pip install -e ".[sim]"         # Micromagnetic / multiscale simulation
uv pip install -e ".[figure]"      # Figure engine (Matplotlib · SciencePlots · PyVista)
uv pip install -e ".[instr]"       # Instrument / SCPI workflow
uv pip install -e ".[literature]"  # Literature search + RAG (LanceDB · pdfplumber)
uv pip install -e ".[reviewer]"    # Peer-review panel
uv pip install -e ".[authoring]"   # Journal drafting · BibTeX · slides · poster
uv pip install -e ".[gateway]"     # Slack / Telegram / Discord gateway
uv pip install -e ".[mcp]"         # MCP server + client
uv pip install -e ".[all]"         # Everything above

# Development
uv pip install -e ".[dev]"         # ruff · mypy · pytest · pre-commit
```

Or with pip:

```sh
pip install -e ".[all]"
```

## Quick start (< 60 s)

```sh
# 1. Register an LLM key (stored in system keyring)
maglab auth set anthropic sk-ant-...

# 2. Verify the connection
maglab auth test anthropic

# 3. Run a deterministic physics calculation (no LLM, no key needed)
maglab physics compute exchange_length A=13e-12 Ms=860e3
# → exchange_length(A=1.3e-11, Ms=860000.0) = 5.33e-09

# 4. Convert units
maglab physics units 1000 Oe T
# → 1000.0 Oe = 0.1 T

# 5. Look up a material
maglab mat show Permalloy
# → Ms, A, K, alpha, T_C, g, source DOI

# 6. Start the interactive REPL (requires a key)
maglab
```

The REPL accepts natural-language research queries and orchestrates the tool chain
automatically. It records every step to the W3C PROV ledger and surfaces provenance
badges on all DataPoints.

## Architecture overview

```
maglab/
├── core/          Orchestrator · hook registry · autonomy gate · budget tracker ·
│                  checkpoint/resume · context engine · model router · manifest loader ·
│                  Ralph autonomous loop · sub-agent dispatcher
├── llm/           Multi-backend LLM abstraction (litellm · Ollama · OpenAI-compat) ·
│                  credential manager · tool definitions · MCP client
├── physics/       Deterministic formula library · SI unit converter ·
│                  physics oracle · curated materials DB · Quantity type
├── sim/           Micromagnetic single-scale (OOMMF · MuMax3 · magnum.np) ·
│                  DFT parser (VASP/QE) · atomistic (VAMPIRE) · multiscale handoff ·
│                  macrospin + 2-sublattice LLG · custodian job runner
├── analysis/      Effect-fitting registry (~25 effects) · bilevel optimiser ·
│                  calibration · consistency checker · symmetry analyser ·
│                  device FoM registry
├── figure/        DataPlot renderer · schematic primitives catalog (11 primitives) ·
│                  micromagnetics visualiser · composition engine · export with provenance
├── instrument/    SCPI workflow · safety gate · manual RAG · PyVISA-sim mock ·
│                  skill generator
├── literature/    OpenAlex · Semantic Scholar · arXiv · Crossref connectors ·
│                  corpus + RAG · author graph · keyword extractor · journal DB ·
│                  evidence matrix · citation auditor
├── reviewer/      Multi-persona panel · meta-reviewer · APL rubric · corpus RAG ·
│                  AI disclosure
├── authoring/     Section drafter · BibTeX manager · citation auditor · data vault ·
│                  journal templates · slide / poster drafter · communications
├── lab/           Electronic lab notebook · measurement planner · DOE · active learning
├── gateway/       Slack · Telegram · Discord adapters · daemon runner · session DB
├── provenance/    DataPoint model · W3C PROV ledger · store
├── report/        Honesty gate · report renderers
└── mcp_server.py  MCP server (expose tools to external agents)
```

Sub-agents (defined in `harness.manifest.json`): `citation-auditor`,
`local-context-librarian`, `paper-reviewer`, `physics-validator`, `result-analyst`,
`search-scout`, `synthesis-editor`, `comms-writer`, `experiment-manager`,
`hypothesis-gen`. Workflows: `survey`, `paper-review`, `citation-map`, `local-gap`,
`physics-validation`, `result-analysis`, `hypothesis-generation`.

## Test suite

```sh
pytest                    # full suite
pytest -m smoke           # CLI startup smoke tests
pytest -m integrity       # honesty gate · citation audit · SCPI safety
pytest -m golden          # µMAG / VAMPIRE / literature formula regression
pytest -m integration     # pipeline integration tests
```

195 source files, zero mypy issues, ruff-clean. LLM-as-judge is explicitly prohibited
for quantitative, citation, and fitting validation (§20 of the design spec).

Test markers:
- **smoke** — every Appendix-A CLI command wires to a real implementation (verified at import)
- **integrity** — honesty gate blocks bare floats; oracle hook blocks α = 50, T = −10 K;
  SCPI gate blocks `TEMP 9999`; persona disclosure is present in review output
- **golden** — deterministic formula checks against µMAG benchmark values and literature
  constants; VAMPIRE / magnum.np runs skipped cleanly without external binaries
- **integration** — full multi-step pipeline runs (sim → fit → figure → export)

## Accepted deferrals

These items are explicitly documented and do not block any implemented feature:

- **µMAG golden tests** use deterministic formula checks rather than live solver runs.
  Live runs require external binaries (magnum.np / OOMMF / MuMax3) absent from CI;
  the corresponding tests skip cleanly.
- **Spin mixing conductance** is implemented under the `spin_orbitronics` provider
  rather than `ferromagnetic_resonance` — a provider-placement cosmetic deviation.
