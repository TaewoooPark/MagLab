## Why MagLab

Experimental spintronics groups face a fragmented toolchain: separate scripts for
micromagnetic simulation, effect fitting (ST-FMR, ISHE, anomalous Hall, …), literature
search, figure generation, and manuscript drafting — none of them talk to each other,
and none of them record where a number came from.

MagLab integrates the full research lifecycle in one tool built on a strict principle:
the **LLM reasons and plans; deterministic engines compute**. There are no benchmark
numbers invented by a language model, no citations hallucinated from a plausible-sounding
title, no figure data generated by sampling a neural network. Every DataPoint carries a
provenance type (`SIMULATED | MEASURED | THEORY | LITERATURE | FITTED`), a source
reference, and SI units — and an oracle hook blocks physically impossible inputs before
any computation runs.

## Verifiable orchestrator — the core principle

![MagLab agent architecture](image2.png)

**Three layers that must never blur:**

1. **LLM** — reasoning, planning, tool selection, narrative drafting, figure code authoring.
   Nothing beyond this.
2. **Deterministic tools** — simulation, fitting, theoretical formulae, units, materials,
   literature retrieval, citation verification, figure rendering.
   All numbers, citations, and figure data originate exclusively here.
3. **Provenance** — source and lineage of every `DataPoint`, citation, and decision (W3C PROV).

**Honesty gates** run at two points: the oracle hook fires before any physics tool call
(blocking unphysical parameters with a physics reason); `HonestyGate` fires at the REPL
output boundary (blocking bare float values not wrapped in a `DataPoint`).

## Installation

Python 3.11–3.13 required. All core modules install without a GPU or a live LLM key.

```sh
# Recommended — create an isolated env first
uv venv --python 3.12 && source .venv/bin/activate

# Core (physics · provenance · CLI · REPL · PROV ledger)
uv pip install -e .

# Install only what you need — extras are independent
uv pip install -e ".[llm]"         # LLM backends (litellm + Ollama)
uv pip install -e ".[sim]"         # Micromagnetic / multiscale simulation
uv pip install -e ".[figure]"      # Figure engine (Matplotlib · SciencePlots · PyVista)
uv pip install -e ".[instr]"       # Instrument / SCPI workflow
uv pip install -e ".[literature]"  # Literature search + RAG (LanceDB · pdfplumber)
uv pip install -e ".[reviewer]"    # Peer-review panel
uv pip install -e ".[authoring]"   # Journal drafting · BibTeX · slides · poster
uv pip install -e ".[gateway]"     # Slack / Telegram / Discord gateway
uv pip install -e ".[mcp]"         # MCP server + client
uv pip install -e ".[all]"         # Everything above

# Development
uv pip install -e ".[dev]"         # ruff · mypy · pytest · pre-commit
```

Or with pip:

```sh
pip install -e ".[all]"
```

## Quick start (< 60 s)

```sh
# 1. Register an LLM key (stored in system keyring)
maglab auth set anthropic sk-ant-...

# 2. Verify the connection
maglab auth test anthropic

# 3. Run a deterministic physics calculation (no LLM, no key needed)
maglab physics compute exchange_length A=13e-12 Ms=860e3
# → exchange_length(A=1.3e-11, Ms=860000.0) = 5.33e-09

# 4. Convert units
maglab physics units 1000 Oe T
# → 1000.0 Oe = 0.1 T

# 5. Look up a material
maglab mat show Permalloy
# → Ms, A, K, alpha, T_C, g, source DOI

# 6. Start the interactive REPL (requires a key)
maglab
```

The REPL accepts natural-language research queries and orchestrates the tool chain
automatically. It records every step to the W3C PROV ledger and surfaces provenance
badges on all DataPoints.

`harness.manifest.json` turns this tree into an agent society rather than a single
monolith: `local-context-librarian` checks the user's corpus, `search-scout` expands
query families, `citation-auditor` validates metadata and retractions,
`paper-reviewer` reads verified papers in depth, `synthesis-editor` writes the final
synthesis, `physics-validator` checks dimensional and physical plausibility,
`result-analyst` digests simulation and measurement batches, `experiment-manager`
owns the research tree, `hypothesis-gen` ranks falsifiable hypotheses, and
`comms-writer` translates technical conclusions into external communications.

## Accepted deferrals

These items are explicitly documented and do not block any implemented feature:

- **µMAG golden tests** use deterministic formula checks rather than live solver runs.
  Live runs require external binaries (magnum.np / OOMMF / MuMax3) absent from CI;
  the corresponding tests skip cleanly.
- **Spin mixing conductance** is implemented under the `spin_orbitronics` provider
  rather than `ferromagnetic_resonance` — a provider-placement cosmetic deviation.
