## 15. 원고 리뷰 — 전문가 페르소나 패널 (`reviewer/`)

### 15.1 개념

논문 주제·원고 → 권위 연구자 탐색(§14.2) → 각 연구자의 공개 논문 코퍼스에
RAG 그라운딩된 리뷰어 에이전트 → 패널(3인) 병렬 리뷰 → 메타리뷰 → 리뷰·패치
Ralph 루프.

### 15.2 ★ 연구 무결성 — 협상 불가

실명 인물 모델링은 명예훼손·퍼블리시티권 위험을 수반한다. 7대 안전장치
(`reviewer/disclosure.py` 강제): ① 모든 출력에 고지 라벨("[저자]의 공개 논문
N편으로 모델링된 AI 리뷰어, [저자]의 실제 의견·승인 아님") ② 1인칭 귀속 금지
(3인칭 추론형) ③ 날조 인용 금지(검색 청크 축자 발췌+DOI만) ④ 공개·발표된
입장으로 범위 한정 ⑤ 코퍼스 밖 전문성 날조 금지 ⑥ 옵트아웃 레지스트리
⑦ "AI 리뷰어(코퍼스 모델)"로 명명. 산출물은 본인 원고 준비용 피드백이다.

### 15.3 코퍼스 RAG · 루브릭 · 패널

저자 코퍼스(S2/arXiv) → SPECTER2 임베딩 → LanceDB + BM25 하이브리드. 루브릭:
신규성·건전성·중요성·명료성·종합(물리 저널 정렬), 각 점수에 근거 절 의무.
3인 패널 병렬 → `meta_reviewer` 합의·이견 종합. 참고: DeepReviewer·MARG.

### 15.4 저널별 리뷰 루브릭

§15.3의 일반 루브릭을 *대상 저널별*로 특화한다. 페르소나 패널이 투고 대상
저널의 실제 기준으로 평가한다.

- 자성/스핀트로닉스 주요 저널별 루브릭 — PRL·PRB·PRX·npj Computational
  Materials·APL Materials·Nature 자매지 등. 각 저널의 신규성·중요성 문턱,
  길이·구조 요건, 전형적 거절 사유를 인코딩한다.
- 점수는 그 저널 척도에 정렬한다(예: PRL = 광범위 관심·즉시성 강조). 구조화
  JSON 출력(점수 + 사유 + 근거 절).
- **보정 모드** — 알려진 채택/거절 논문 집합에 패널을 돌려 거짓음성·거짓양성
  률을 측정·표시. 패널이 과대긍정으로 치우치지 않게 한다.

### 15.5 리뷰→패치 Ralph 루프 (Loop A)

패널 인스턴스화 → 라운드1 병렬 리뷰 → 메타리뷰 → 패치 생성(검증 인용 그라운딩)
→ **휴먼게이트(Tier 3, diff별 승인)** → 라운드2 델타 리뷰 → 점수 임계/max 회수
종료. provenance에 전 라운드 기록. 원고 변경은 항상 사람 승인.
